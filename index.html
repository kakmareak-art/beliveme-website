Core Application Features

Built with Jetpack Compose, Material 3, and native Android AlarmClock APIs for maximum reliability.

📅

Frozen IST Timetable

Structured Monday–Friday, Saturday, and Sunday routines strictly locked to Asia/Kolkata (IST) timezone with live time highlighting and remaining-time badges.

🗣️

English Practice Checklist

5-step structured daily practice covering listening, reading aloud, sentence writing, speaking practice, and mistake review with daily topic guides.

💼

LIC Agent Work Helper

4-step activity checklist, prospect contact list manager, follow-up scheduler, and activity completion metrics without customer document storage.

Trading Session Discipline

Pre-market checklists for London and Evening sessions. Tracks rule compliance and 'No Setup / No Trade' discipline. Displays mandatory trading-end alerts.

Saturday Backlog Queue

Automatically carries forward pending weekday English and LIC tasks into a Saturday catch-up queue without cluttering Sundays.

🔒 Privacy Policy & Data Security

BeliveMe is built on a strict privacy-first foundation:

  • 100% Local & Offline: All schedule records, notes, checklists, and contacts are saved strictly on your local device using Android private SharedPreferences.
  • Zero Tracking & Zero Analytics: The app contains no third-party trackers, analytics SDKs, advertising frameworks, or cloud databases.
  • Complete User Control: You can export your full application history to an encrypted JSON backup file anytime or restore it using Android's native Document Picker.
